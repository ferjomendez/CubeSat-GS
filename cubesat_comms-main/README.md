# CS Comms files

- ESP32_LoRa_Handler.ino: Used for data transmitting or receiving packets.
- GS_beacon_receive.py: Temp code used for testing the reception of packets.
- OBC_sim.py: Used for simulating packet transmission from OBC to ground station (GS), using the CCSDS structure for packets (CCSDS 133.0-B-2), check blue books (recommended standards).
